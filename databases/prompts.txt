→ 10 entrées par champ
→ structure simple, claire, immersive

Voici la structure :

js
Theme_Objet: {
  name: [ ...10 entrées... ],
  description: [ ...10 entrées... ],
  properties: [ ...10 entrées... ],
  origin: [ ...10 entrées... ],
  secret: [ ...10 entrées... ]
}
Définitions :

name : nom de l’objet

properties : capacités, effets, usages, comportements

secret : révélation, anomalie, danger, pouvoir caché
