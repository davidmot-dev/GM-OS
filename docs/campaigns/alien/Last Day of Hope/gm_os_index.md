# GM-OS — index opérationnel pour IA MJ

> Mots-clés : #gm_os #index #workflow #retrieval

## Objectif commun
Quitter LV-426 vivants en récupérant l’accès à la navette.

## Nœuds de progression
1. **Départ** — sas Ouest, message d’urgence, silence anormal.
2. **Compréhension** — la colonie est perdue, aucun secours interne fiable.
3. **Recherche de solution** — trouver Reynolds ou Komiskey.
4. **Acquisition de ressource** — récupérer carte d’accès / information / matériel.
5. **Montée de menace** — facehugger, drones passifs puis actifs, appels, naissance.
6. **Ruée finale** — atteindre la navette.
7. **Dernier piège** — œufs / facehuggers déjà dans la navette.

## Clés de retrieval
### Questions type
- Où trouver une carte d’accès pour la navette ?
- Quel lieu contient Komiskey ?
- Quel xéno se cache dans le bloc C1 ?
- Comment déclencher la montée de pression si les PJ stagnent ?
- Quelles armes peuvent être récupérées dans le sous-sol ?
- Que se passe-t-il si Komiskey est sauvée ?
- Comment finir le scénario ?

## Réponses cibles
- Carte d’accès : Komiskey, potentiellement Reynolds.
- Komiskey : médilab du bloc E2.
- Bloc C1 : facehugger passif dans les conduites.
- Pression : Appel au secours, Naissance, Pris en chasse.
- Armes sous-sol : M41A, M4A3, M240 sans recharge.
- Sauvetage de Komiskey : information + future naissance de chestburster.
- Fin : fuite vers navette puis confrontation facehugger.
