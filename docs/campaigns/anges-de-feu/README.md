# Anges de Feu

Documents de campagne lus par l'Oracle : lore, lieux, PNJ, fils narratifs, notes de séance.

**Pour que ce dossier soit lu**, renseigner son chemin dans la fiche de campagne, champ
**« Chemin des Notes »** :

```
campaigns/anges-de-feu
```

Sans ce chemin, le moteur retombe sur le nom du dossier, qui ne correspond pas toujours au nom de la
campagne — c'est pourquoi l'Oracle signalait « aucun document rattaché ».

Ce qui est déposé ici est **prioritaire sur les extraits bruts du système**, mais passe après les
fiches de règles : une question de règle reste arbitrée par `docs/systems/<système>/rules/`.
