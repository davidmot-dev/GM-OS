Remplir la fiche COC2

Cette fiche de Chroniques Oubliées Contemporain reproduit les deux pages du PDF fourni, sans recoloration. « Zones » montre les contrôles transparents. Aucun emplacement de portrait n’est imprimé : aucun n’est ajouté.

La première page porte l’identité, les sept caractéristiques et leurs notes, la description, trois avantages/désavantages, deux lignes d’équipement, les valeurs de combat, trois armes, une protection et les séquelles. Les libellés et préfixes « 1D20 + » restent ceux du PDF. BDM et DM sont des textes libres ; les autres valeurs chiffrées acceptent notamment les nombres négatifs. Aucun calcul de règle n’est ajouté.

Les deux échelles imprimées sont des jauges de 0 à 20 : cliquer une cellule allume celles qui la précèdent ; recliquer la valeur courante revient à zéro. Les cellules larges de santé correspondent à 5, 10, 15 et 20. L’échelle de la page 2 est enregistrée sous un nom générique : aucun rôle non imprimé sur le document ne lui est attribué automatiquement.

La seconde page comporte six Voies. Chaque rang a son nom, sa description et une case indépendante ; cocher une capacité ne coche pas les autres rangs. Aucun prérequis ni progression n’est imposé par cette fiche.

Zoom de 20 à 400 %, Ctrl+molette, Ctrl++, Ctrl+− ; Ctrl+0 ajuste la page. Sauvegarde automatique dans ce navigateur ; exportez régulièrement un JSON pour conserver une copie. L’import remplace les données après confirmation si la fiche est remplie ; la réinitialisation demande confirmation.

Imprimer produit les deux pages, même si une seule est affichée à l’écran, aux dimensions originales de 473,386 × 609,449 points. Une saisie très longue peut défiler dans son champ : relisez le rendu imprimé. Le manifeste est importable dans le moteur GM-OS ; intégration permanente et correspondance avec le pilote restent des étapes séparées.
