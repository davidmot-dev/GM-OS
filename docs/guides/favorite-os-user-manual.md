# 🗂️ Manuel Utilisateur : Favorite-OS (Favoris & Inventaire)

Le module **Favorite-OS** est votre centre de commande pour les éléments les plus critiques de votre campagne : PNJ majeurs, lieux emblématiques, objets légendaires et lore essentiel.

## 1. Types d'Entités

Favorite-OS permet de classer vos favoris en quatre catégories :
- **👤 PNJ (NPC)** : Personnages non-joueurs importants avec portrait et biographie.
- **🗺️ Lieu (Location)** : Points d'intérêt géographiques ou scènes clés.
- **📦 Objet (Item)** : Équipements, armes ou reliques (utilisés pour l'inventaire des joueurs).
- **📜 Lore** : Fragments d'histoire, secrets ou informations narratives.

## 2. Le Pont Magique (Wiki ➔ Favoris)

Si vous utilisez le module **Session-OS**, vous pouvez importer des articles de votre Wiki directement dans Favorite-OS d'un simple clic :
1. Allez dans l'onglet **Wiki** du Session-OS.
2. Sélectionnez un article.
3. Cliquez sur le bouton "Action Magique" (ex: 📦 Ajouter aux Favoris).
4. Le système crée automatiquement le favori, pré-remplit les données et **lie la campagne actuelle** sans action supplémentaire.

## 3. Gestion de l'Inventaire Joueur

Transférer un objet du MJ vers le sac à dos d'un joueur n'a jamais été aussi simple :

### Étape A : Créer l'Objet
Assurez-vous que l'entité est de type **Objet (Item)**. Remplissez le champ "Lore" avec la description que le joueur pourra lire.

### Étape B : Assignation
Dans le panneau de détails du favori :
1. **Campagne** : Sélectionnez la campagne de la session en cours.
2. **Propriétaire (PJ)** : Une liste déroulante des Personnages Joueurs (PJ) de cette campagne apparaîtra. Sélectionnez le destinataire.

### Étape C : Synchronisation
Activez l'interrupteur **"Synchroniser avec le Hub"** (icône d'antenne). 
- Si l'objet est assigné à un joueur, seul ce joueur le verra dans son onglet "Sac" sur sa tablette.
- Si aucun propriétaire n'est défini, l'objet reste public et visible par tous les joueurs (ex: un parchemin lu par tous).

## 4. Astuces de MJ (Sally & Carson)
- **Image Narrative** : Utilisez des portraits immersifs. L'image que vous mettez dans le favori est celle qui s'affichera en plein écran sur la tablette du joueur.
- **Notes Secrètes** : Seul le champ "Lore" est visible pour le joueur. Vous pouvez garder vos notes techniques privées dans d'autres champs si besoin.
