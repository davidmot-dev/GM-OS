# Errata du livre de base français — 2021

Ces corrections concernent le livre de base français de David, pas Evolved Edition.
L'errata du 04/11/2021 reprend les corrections du 09/04/2021.

- **Pages 78–79, Guérison rapide** : le temps de guérison d'une blessure critique est divisé par deux.
- **Pages 78–79, Rechargement rapide** : recharger coûte une action rapide au lieu d'une action lente.
- **Page 199, avaries mineures, D66 = 55** : unité de réfrigération endommagée.
  La nourriture réfrigérée est perdue au bout d'une journée ; réparation par Machines lourdes.

L'autre correction de novembre vise le profil du Bodyburster dans *Le Destructeur des Mondes*.
Elle ne modifie pas le livre de base. Cet errata ne tranche pas l'égalité de deux tests de
Panique ; le texte du livre français p. 104 dit « inférieur » pour le remplacement par
l'effet un cran au-dessus.
