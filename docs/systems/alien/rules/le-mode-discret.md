# Le Mode Discret (Infiltration et Détection)
## Règle
Le Mode Discret régit l'exploration silencieuse et l'infiltration dans ALIEN, le jeu de rôle, représentant la phase précédant le combat (p. 85). Le temps y est divisé en Tours de cinq à dix minutes (p. 83, 85). Durant chaque Tour, un personnage peut traverser deux zones du plan et les explorer (p. 85). Examiner un élément de plus près requiert un Tour complet (p. 85). Les ennemis se déplacent secrètement sous le contrôle de Maman après le mouvement des personnages (p. 85). La détection automatique s'applique si aucune discrétion n'est tentée (p. 85). Pour s'infiltrer ou surprendre un ennemi passif, le personnage doit réussir un test de sa compétence Mobilité opposé à l'Observation de la cible (p. 85, 86). L'échec entraîne la détection immédiate et l'arrêt du Mode Discret pour lancer le combat (p. 86).

## Valeurs
- Durée d'un Tour : de cinq à dix minutes (p. 83, 85).
- Déplacement : deux zones par Tour (p. 85).
- Détecteur de mouvement : utilisable une fois par Tour (p. 86).
- Portée du détecteur M314 : Longue (quatre zones) en intérieur, Extrême (un kilomètre) en extérieur (p. 82, 86).
- Test de Réserve du détecteur : requis après utilisation, lance des dés de stress égaux à la Réserve actuelle (p. 34, 86).
- Réduction de Réserve : chaque symbole de panique (un un) obtenu sur les dés de stress diminue la Réserve de un point (p. 34).
- Modificateurs de distance pour le test de Mobilité d'infiltration (p. 86) :
  - Portée Courte (même zone) : modificateur de -1.
  - Portée Moyenne (zone adjacente) : modificateur de 0.
  - Traversée d'une porte, trappe ou sas ouverts : modificateur de +2.
  - Portée Longue : modificateur de +1.
  - Portée Extrême : modificateur de +3.
- Modificateurs de distance pour une attaque furtive ou embuscade (p. 90) :
  - Contact : modificateur de -2.
  - Portée Courte : modificateur de -1.
  - Portée Moyenne : modificateur de 0.
  - Portée Longue : modificateur de +1.
  - Portée Extrême : modificateur de +3.
  - Embuscade (cible en mouvement) : modificateur de +2 (p. 90).

## À la table
1. Maman décrit les lieux superficiellement à chaque Tour de Mode Discret (p. 85).
2. Les joueurs déclarent leurs mouvements de zones et leurs intentions d'exploration (p. 85).
3. En cas de déplacement silencieux collectif, le joueur dont le personnage possède le plus bas niveau en Mobilité lance les dés pour tout le groupe (p. 67, 85).
4. Maman déplace secrètement les ennemis sur son plan personnel ou un morceau de papier (p. 85).
5. Pour localiser les menaces hors de vue, un personnage utilise son détecteur en effectuant un test de Réserve d'Énergie (p. 86). Si un mouvement est repéré, un pion est placé sur le plan (p. 86).
6. Si le groupe entre dans la zone d'un ennemi passif sans être discret, la détection est automatique et l'initiative est tirée (p. 85, 87).
7. Pour s'infiltrer ou attaquer furtivement, le joueur effectue un test de Mobilité opposé à l'Observation de l'ennemi (p. 85). La réussite octroie une action gratuite (lente ou rapide) avant le tirage de l'initiative, sans possibilité pour la cible de bloquer (p. 90). L'échec arrête le Mode Discret pour lancer le combat (p. 86, 90).

## Cas limites
- Ennemis actifs dissimulés : Un ennemi actif restant caché sans attaquer ne peut pas être détecté sans détecteur de mouvement, sauf si le groupe fouille précisément son abri (p. 85).
- Énergie du détecteur : L'appareil s'éteint dès que sa jauge de Réserve d'Énergie tombe à zéro (p. 34, 86).
- Cibles immobiles : Le détecteur ne repère que les objets en mouvement. Si l'ennemi reste immobile, il n'est pas détecté (p. 86).
- Ligne de vue : Détecter une menace n'équivaut pas à une détection visuelle directe (p. 86). Pour attaquer, le personnage doit se trouver dans la même zone et posséder une ligne de vue dégagée (p. 83, 86).
- Tests de groupe : En déplacement collectif, le moins compétent en Mobilité effectue le test (p. 67). Pour l'Observation collective, c'est le plus compétent qui lance les dés (p. 67).
- Surprise par un ennemi actif : Un ennemi actif peut tenter une attaque furtive (p. 85). Maman effectue un test de Mobilité contre l'Observation de la cible. Si l'ennemi réussit, il gagne une action gratuite avant l'initiative (p. 85, 90).

## Non couvert
- Le livre ne précise pas le modificateur de discrétion appliqué si le personnage rampe au lieu de courir (p. 85).
- Aucun modificateur d'encombrement physique ou d'objets lourds n'est détaillé pour la discrétion, hors surcharge en combat (p. 34).
- Les effets d'un environnement bruyant (alarmes, réacteurs) sur l'Observation ou l'efficacité des détecteurs sont absents des sources (p. 85).
- Aucun modificateur de discrétion dans l'obscurité n'est mentionné pour les synthétiques ou les xénomorphes, hors leurs compétences (p. 111, 290).
