# Intention visuelle — Blade Runner

Interface néo-noir aux panneaux d’encre bleutée, avec un grain de papier froid et des traits techniques ambrés. Les angles sont francs, le relief profond et les lueurs corail rappellent une ville nocturne rétrofuturiste.

## Limites

- **PARTIELLEMENT RÉALISABLE** — La matière, les halos, le verre et les couleurs d’état passent par des jetons V2 : ils resteront sans effet visible dans la version actuelle de GM-OS.
- **NON EXPRIMABLE** — La mise en page éditoriale, les doubles cadres, les séparateurs segmentés et les détails des composants `.rpg-*` appartiennent à la démonstration du SDK ; les jetons du contrat ne permettent pas de les reproduire dans GM-OS.
