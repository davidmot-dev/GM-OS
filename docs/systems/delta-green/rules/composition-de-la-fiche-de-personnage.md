# Composition de la fiche de personnage

## Règle
La fiche d’Agent (formulaire DD 315) réunit six rubriques (sections « Description d'un Agent », « Fiches de personnage »):
- Données personnelles: état civil, métier, employeur et parcours (sections « Description d'un Agent », « Description détaillée: Derniers détails »).
- Caractéristiques: six aptitudes (FOR, DEX, CON, INT, POU, CHA) (section « Description détaillée: caractéristiques »).
- Attributs dérivés: jauges vitales (PV, VOL, SAN, Seuil de Rupture; voir Santé et blessures) (section « Description détaillée: attributs dérivés »).
- Psychologie: Attaches, motivations et accoutumance (sections « Description détaillée: Les Attaches », « Description détaillée: Derniers détails »).
- Compétences: pourcentages avec cases de progression (sections « Description détaillée: Profession », « Fiches de personnage »).
- Matériel et combat (au verso): armes, armure et blessures (section « Fiches de personnage »).

## Valeurs
- Caractéristiques (section « Description détaillée: caractéristiques »):
  - Échelle ordonnée: 3 (infirme) à 18 (exceptionnel), moyenne 10.
  - Tirage: 4D6 (3 meilleurs dés), 6 fois.
  - Répartition: 72 points (ou séries: 13, 13, 12, 12, 11, 11; 15, 14, 12, 11, 10, 10; 17, 14, 13, 10, 10, 8).
  - Test: caractéristique multipliée par cinq.
- Attributs dérivés (section « Description détaillée: attributs dérivés »):
  - PV: (FOR + CON) divisé par deux, arrondi au supérieur.
  - VOL: POU.
  - SAN: POU multiplié par cinq (plafond 99 moins Inconcevable).
  - Seuil de Rupture: SAN moins POU.
- Psychologie (sections « Description détaillée: Les Attaches », « Description détaillée: Derniers détails »):
  - Attaches: 1 à 4 selon le métier; score égal au CHA.
  - Motivations: jusqu'à 5 au départ.
  - Accoutumance: 3 cases en Violence et 3 cases en Impuissance.
- Compétences (sections « Description détaillée: Profession », « Fiches de personnage »):
  - Base: 0 % à 40 %.
  - Bonus: 8 compétences à +20 %.
  - Plafond initial: 80 %.
  - Échec: +1D4 % par case cochée après la partie.

## À la table
En cours de partie, le joueur utilise sa fiche d’Agent comme tableau de bord opérationnel (section « Description d'un Agent »).

Lorsqu'un test est requis, le joueur repère la compétence concernée ou calcule le score de caractéristique multipliée par cinq. Si le test de compétence échoue, il coche aussitôt la petite case de progression située à côté de l'intitulé (section « Fiches de personnage »). Entre deux opérations, lors du débriefing de fin de séance, chaque case cochée donne droit à un jet d'amélioration: le joueur lance un dé à quatre faces et ajoute ce résultat au pourcentage de la compétence, puis décoche la case.

Quand un affrontement éclate, le joueur se réfère au verso de sa fiche où sont consignées les armes, leurs portées et leurs dégâts ou valeurs de létalité, ainsi que l'armure portée (section « Fiches de personnage »). Les pertes de Points de vie et de Volonté y sont décomptées en temps réel au crayon à papier.

Face aux horreurs et aux traumatismes, le joueur surveille son score de Santé Mentale et son Seuil de Rupture. S'il choisit de projeter son traumatisme sur un être cher pour sauver sa lucidité, il diminue immédiatement la valeur chiffrée de l'Attache correspondante sur sa fiche (sections « Description détaillée: Les Attaches », « Projeter son traumatisme sur une Attache »). Si la Santé Mentale atteint le Seuil de Rupture, le joueur efface l'une de ses motivations personnelles pour inscrire à la place un trouble psychique permanent (section « Troubles psychiques »).

## Cas limites
- Score de caractéristique altéré: si une blessure permanente ou une maladie modifie définitivement la Force, la Constitution ou le Pouvoir, le joueur doit recalculer immédiatement les attributs dérivés correspondants (Points de vie, Volonté ou Santé Mentale) (sections « Blessure permanente », « Description détaillée: attributs dérivés »).
- Perte d'Attache définitive: lorsqu'une Attache tombe à zéro, la mention est barrée ou effacée définitivement; elle ne peut plus être augmentée ni récupérée par des scènes privées (sections « Description détaillée: Les Attaches », « Vie quotidienne »).

## Non couvert
Les sources ne fournissent pas de système d'alignement moral codifié sur la fiche, ni d'inventaire à cases d'encombrement strict pour l'équipement transporté en dehors du bon sens de l'Officier Traitant.
