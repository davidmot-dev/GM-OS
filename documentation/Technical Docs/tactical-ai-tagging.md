# 🏷️ Guide de Tagging : Cerveau Tactique (Media Hub)

Ce document répertorie les tags recommandés pour optimiser la curation audio automatique par l'IA. Pour une efficacité maximale, utilisez ces mots-clés dans les métadonnées de vos fichiers dans le **Media Hub**.

## 1. 🎭 Ambiances & Météo (Chronos)
*Ces tags permettent à l'IA de caler l'ambiance sur le moment de la journée ou les conditions climatiques.*
- `aube`, `crepuscule`, `nuit`, `pleine_lune`
- `orage`, `pluie`, `brouillard`, `neige`, `tempete`, `vent`, `canicule`

## 2. 🐉 Intensité Narrative (Tempo)
*Utilisés pour changer la dynamique sonore en fonction de l'action.*
- `calme`, `exploration`, `mystere`, `tension`
- `combat`, `boss_fight`, `course_poursuite`, `infiltration`
- `tragique`, `heroique`, `epique`, `horreur`

## 3. 🏰 Biomes & Lieux (Topos)
*Définissent le cadre géographique sonore.*
- `nature`, `foret`, `montagne`, `plaine`, `marécage`, `ocean`
- `taverne`, `cite`, `village`, `marche`, `eglise`
- `donjon`, `ruines`, `caverne`, `crypte`, `egouts`
- `espace`, `laboratoire`, `temple`

## 4. 🔮 Matériaux & Magie (Logos)
*Spécifiques pour les effets sonores (SFX) et les détails.*
- `métal`, `bois`, `pierre`, `verre`, `liquide`
- `magie_arcanique`, `magie_divine`, `feu_follet`, `portail`
- `foule`, `cris`, `animaux`, `mecanique`

---
> [!TIP]
> **Conseil MJ** : Plus le tag est simple, mieux l'IA le comprendra. Vous pouvez combiner plusieurs tags (ex: `foret` + `pluie` + `mystere`) pour une ambiance ultra-précise.
