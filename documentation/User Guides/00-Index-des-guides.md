# 🗂️ Les guides utilisateur de GM-OS

> **Les fichiers sont numérotés par famille**, dans l'ordre de cette page : `0x` pour démarrer,
> `1x` la préparation, `2x` le monde, `3x` le jeu, `4x` les tables et le butin, `5x` les règles,
> `6x` les tablettes, `7x` l'ambiance, `8x` l'IA, `9x` transporter et régler. *Le dossier se lit
> donc dans le même ordre que cet index, sans l'ouvrir.*
>
> Renommés le 2026-09-05, à la demande de David : les noms portaient **quatre suffixes différents**
> (`_User_Guide`, `_Guide`, `_User_Manual`, aucun), **deux langues mêlées** et trois conventions de
> casse. Le titre de chaque page reprend désormais son libellé ici — *nom de fichier, entrée
> d'index et titre disaient trois choses différentes.*

**Les 52 guides du dossier, rangés par ce que vous cherchez à faire.** Chaque ligne dit à quelle
question la page répond — de quoi choisir sans ouvrir.

> Vous cherchez plutôt *comment c'est fait* ? → [Index technique](../Technical%20Docs/00_Index_Technique.md)
> Vous cherchez *où en est le projet* ? → [Registre des chantiers](../Planning/2026-08-23-chantiers-gares.md)

## 🔗 Les paires qui se lisent dans l'ordre

**Ce ne sont pas des doublons.** Vérifié le 2026-09-05 : chacune de ces paires se répartit le
travail et se renvoie déjà l'autre. Ce qui prêtait à confusion, c'étaient **leurs noms** — d'où le
renommage du même jour. Lisez quand même la première d'abord :

- **Tablet Hub** *(les joueurs)* : [61-Tablette-des-joueurs](./61-Tablette-des-joueurs.md), puis [62-Tablette-des-joueurs-reglages-fins](./62-Tablette-des-joueurs-reglages-fins.md).
- **Votre tablette** : [60-Tablette-du-meneur](./60-Tablette-du-meneur.md) — à ne pas confondre avec les précédents.
- **Cortex** : [82-Cortex-OS](./82-Cortex-OS.md), puis [83-Cortex-OS-aide-memoire](./83-Cortex-OS-aide-memoire.md).
- **Oracle** : [80-Oracle-poser-une-question](./80-Oracle-poser-une-question.md), puis [81-Oracle-le-pont-NotebookLM](./81-Oracle-le-pont-NotebookLM.md).
