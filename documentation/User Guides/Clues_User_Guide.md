# 🧭 Guide Utilisateur : Système d'Indices (Clues) - v5.2

Le module **Indices** est conçu pour vous aider à gérer les secrets et les preuves de votre campagne. Il centralise tout ce que les joueurs découvrent et permet de l'afficher en un clic.

---

## 🏗️ Création d'un Indice
1. Accédez au **Session-OS** > **Campagne Actuelle** > **Indices**.
2. Cliquez sur **Nouveau Fragment**.
3. Renseignez :
    - **Titre** : Nom de l'indice (ex: "Le Médaillon Sanglant").
    - **Visuel** : Sélectionnez une image via le Media Hub.
    - **Description** : Notez ce que les joueurs découvrent.
    - **Lieu / PNJ Lié** : Liez l'indice à un élément de votre Atlas ou de votre NPC Gallery.
    - **Moment de l'intrigue** (Optionnel) : Notez quand l'indice a été introduit (ex: "Session 4, Découverte au manoir").

---

## 👁️ Révélation & Projection
### Révéler un Indice
Par défaut, un nouvel indice est **Masqué**.
- Cliquez sur l'icône **Œil** pour le révéler aux joueurs.
- **Effet Automatique** : La révélation enregistre un timestamp (`revealedAt`) et crée une entrée dans votre **Journal-OS** pour archiver la découverte.

### Projeter vers le Player Hub
Une fois l'indice révélé, cliquez sur l'icône **Externe** (ou via le Deck de Session) pour l'envoyer sur l'écran des joueurs.

---

## 🎴 Deck de Session (Cockpit MJ)
Pour un accès plus rapide en pleine partie, utilisez le widget **Deck d'Indices** situé en bas de votre tableau de bord (Cockpit).
- Faites défiler vos indices latéralement.
- Utilisez le bouton rapide de projection pour afficher l'indice sur le Hub sans quitter votre vue actuelle.

---

## 📱 TabletHub & Archives (Vue Joueurs)
Les joueurs peuvent consulter l'ensemble des indices déjà révélés via l'onglet **Archives** de leur TabletHub.
- Les indices sont triés par date de découverte.
- Chaque carte affiche le "Moment de l'intrigue" pour rafraîchir la mémoire des joueurs.

---

## 💡 Astuces de Maître de Jeu
- **Liaison Contextuelle** : Si vous ouvrez la fiche d'un PNJ lié à un indice, vous verrez un bouton direct pour consulter ses indices.
- **Journal Automatique** : Utilisez la "Note" générée dans le Journal-OS comme base pour vos récapitulatifs de fin de session.
