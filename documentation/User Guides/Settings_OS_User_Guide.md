# ⚙️ Guide Utilisateur : Paramètres de l'OS

Le module **Paramètres de l'OS** est le centre de contrôle global de GM-OS v5. C'est ici que vous configurez l'esthétique de votre interface, votre matériel physique (écrans, enceintes) et vos services d'intelligence artificielle.

---

## 🎨 Personnalisation (Look & Feel)
GM-OS s'adapte à l'ambiance de votre table :
- **Choix du Thème** : 
    - **Cyberpunk** : Interface sombre, néons et contrastes élevés.
    - **Médiéval** : Textures organiques, parchemin et tons ambrés.
    - **Moderne** : Design épuré, translucide et professionnel.
    - **Claire** : Pour une lisibilité maximale en environnement lumineux.
- **Palette d'Accentuation** : Chaque thème possède son propre jeu de couleurs dynamiques. Cliquez sur une pastille pour changer instantanément la couleur des boutons, des icônes et des lueurs de l'OS.

---

## 🔊 Hardware & Routing (Audio)
Ne vous emmêlez plus les pinceaux avec les noms techniques des périphériques :
- **Identification** : GM-OS liste toutes vos sorties audio physiques.
- **Système d'Alias** : Assignez un nom convivial (ex: "Enceintes MJ", "Table Joueurs") à chaque sortie. Ces noms seront utilisés partout dans les modules Music, Sound et Ambient pour faciliter vos mixages.
- **Actualisation** : Utilisez le bouton "Actualiser" si vous branchez un nouveau périphérique en cours de session.

---

## 🖥️ Moniteurs & Projection (Display)
Gérez vos écrans secondaires pour l'immersion :
- **Multi-Écrans** : Si vous utilisez le **Bridge Electron/Tauri**, tous vos moniteurs branchés apparaissent ici.
- **Alias d'Écran** : Nommez vos écrans (ex: "TV Murale", "Écran Joueurs 1") pour savoir exactement où vous projetez vos cartes et images.

---

## 🤖 Intelligence Artificielle (Cloud & Tactical)
Configurez le "cerveau" de votre OS :
- **AI Oracle** : Saisissez vos clés API et sélectionnez vos modèles de langage pour l'Oracle et la Forge.
- **Cortex Tactique** :
    - **Master Switch** : Activez ou désactivez globalement l'IA d'assistance au combat.
    - **Taxonomie** : Accédez à l'éditeur de taxonomie pour personnaliser la manière dont l'IA interprète les règles et les statuts du jeu.

---

## ⚠️ Zone de Danger
Pour la maintenance et les situations critiques :
- **État du Bridge** : Vérifiez en un coup d'œil si la connexion avec le système hôte (Electron/Tauri) est active.
- **Reset Total** : Efface toutes les données locales, vos campagnes et vos réglages. **Cette action est irréversible.**

---

> [!IMPORTANT]
> **Configuration Initiale** : Lors de votre première utilisation de GM-OS v5, passez par ce module pour nommer vos alias matériels. C'est l'étape clé pour que vos scénarios de lumières et de sons fonctionnent parfaitement !
