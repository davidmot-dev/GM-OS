# Checklist de vérification

- [ ] Pilote : bon jeu, édition, ID, version, gabarit et champs exacts ; sources citées.
- [ ] Matrice : chaque mécanique soutenue possède ses cas ; les fonctions absentes restent signalées.
- [ ] Une seule archive de campagne et un seul ID de campagne pour histoire et ateliers ; tous les cas visent ce fichier. Plusieurs campagnes seulement sur demande explicite. Seuls IDs/noms des joueurs autorisés réutilisés, nouveaux PJ distincts et personnages [RECETTE] identifiés.
- [ ] Relecture narrative : campagne complète, généralement 10 à 15 séances jouables, arcs suivis, réactions et conséquences, plusieurs chemins et fins ; aucune séance réduite à un titre ni intrigue indispensable derrière un unique jet.
- [ ] Ateliers dans un acte hors fiction de la même Trame, accessibles directement ; repères de scènes/personnages dans le cahier et la matrice ; personnages d'essai réservés aux scènes concernées.
- [ ] Archive structurellement cohérente, médias embarqués avec SHA-256 ; zéro lien vers le disque personnel.
- [ ] Scènes/actes/lieux/PNJ/indices/rencontres et liens croisés valides, progression ouverte, pas d'indice essentiel bloqué.
- [ ] Personnages : types, formules, santé, inventaire, initiative, ressources et limites contrôlés avec le pilote et le moteur ; valeurs choisies signalées.
- [ ] Modules : vraie compatibilité, bonnes versions de données, constructeurs réels, droits MJ/PJ ; aucune extension factice.
- [ ] Médias : SVG rendus et relus, WAV réellement décodés/écoutés si le contrôle audio est annoncé. Un fichier existant n'est pas une preuve de décodage.
- [ ] Import natif isolé : une seule campagne ajoutée ; dépendances, campagnes/avatars/PJ sentinelles préservés, rechargement vérifié. Version du pilote déjà installé contrôlée, remplacement explicite si nécessaire.
- [ ] ETATS-DE-REFERENCE.md complet ; remise en état locale réelle ou procédure manuelle annoncée. Essai et restauration préservent une note de fiction et la valeur d'un PJ principal, après rechargement. Aucun Nexus Remplacer annoncé comme reset partiel, aucun bouton/import d'états inventé.
- [ ] Trois tailles de Hub si pertinent : 360, 768, 1180 px ; jets reçus par le MJ ; fiche HTML et écriture/persistance ; accès refusé quand non autorisé.
- [ ] Secrets : marqueurs fictifs dans champs privés, trames joueur vérifiées. Ne pas collecter de vrais secrets dans les preuves.
- [ ] Sorties physiques, IA/TTS, services et matériel : préciser ce qui n'a pas été essayé ; ne pas les déclarer configurés par simple présence de données.
- [ ] Cas humains NON TESTÉS tant que le meneur ne les a pas joués ; anomalies préservées.
- [ ] Rapports liés aux mêmes SHA que le lot final. Toute régénération invalide les rapports dépendants.
- [ ] ZIP relu ; aucun fichier privé, dépendance installée, secret ou ancien ZIP inclus par récursion.

Les cases non faites se transforment en limites explicites dans le rapport. L'absence d'outils applicatifs n'empêche pas une préparation honnêtement marquée PRÉPARÉE ; elle empêche de prétendre avoir réalisé ces essais.
