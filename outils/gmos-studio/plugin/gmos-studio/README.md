# GM-OS Studio

Un accueil commun et six ateliers pour préparer votre jeu :

1. Thème d’interface — RPG Theme Builder.
2. Fiche interactive — Character Sheet HTML Studio.
3. Identité des images — RPG Visual Identity Builder.
4. Bannière — RPG Banner Builder.
5. Table des matières — TOC Extractor.
6. Extraction de cartes — Extracteur de cartes.

Commencez par « Affiche le menu », un numéro ou une demande précise avec vos fichiers.
« Préparer un nouveau jeu » aide à sélectionner et enchaîner les ateliers utiles, en réutilisant
les références déjà fournies. « Menu » permet de changer d’atelier.

Les références, contrats et outils sont inclus dans ce plugin. Il ne faut pas installer les
six plugins d’origine ; ceux-ci ne sont ni modifiés ni supprimés.

Les outils d’exécution, de vision, de PDF et de génération d’images dépendent de l’environnement.
L’extraction des cartes utilise Python, PyMuPDF et Pillow ; aucun serveur n’est nécessaire.
Le plugin ne fournit ni générateur indépendant ni connexion automatique aux données GM-OS.

Les PDF et HTML de référence de fiches sont des exemples d’éditeur déjà présents dans le
constructeur original : paquet privé, sans publication publique ni sources personnelles ajoutées.
