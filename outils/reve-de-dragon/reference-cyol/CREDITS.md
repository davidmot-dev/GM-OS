# Crédits — référence des outils RdD et TMR

## Code et aide de jeu d’origine

**Les Terres Médianes du Rêve : Outils**, par **Cyol**, avec les corrections de **Kroc**
créditées par le site. Version annoncée : 21, 04/01/2017 — corrigée par Kroc.

- Auteur : <https://cyol.fr/blog/>
- Aide de jeu hébergée par Scriptarium : <https://scriptarium.org/RdD/tmr/>
- Archive publiée : <https://scriptarium.org/RdD/tmr/tmr.zip>
- Licence annoncée : **Creative Commons Attribution 3.0 France (CC BY 3.0 FR)**,
  <https://creativecommons.org/licenses/by/3.0/fr/>.

Récupération pour GM-OS le **18/10/2026**. Les cinq fichiers de `originaux/` sont des copies
inchangées. Pour les cinq fichiers de `extraits/`, Codex a sélectionné 26 fonctions et ajouté
une notice ; les corps des fonctions sont inchangés. La sélection, l’index, la provenance et
l’outillage de vérification sont propres à cette préparation GM-OS. Aucune adaptation
fonctionnelle du code tiers ni intégration au moteur de GM-OS n’est livrée à cette date.

## Références tierces mentionnées par les sources

- `tmrHexagon.js` mentionne une adaptation de **Hexagon.js**, dépôt
  <https://github.com/rrreese/Hexagon.js>, et l’article de géométrie
  <http://blog.ruslans.com/2011/02/hexagonal-grid-math.html>. Ces références restent dans le
  fichier original ; les mentions et conditions applicables devront accompagner toute reprise.
- **Rêve de Dragon** est le jeu de **Denis Gerfaud**, édité notamment par **Scriptarium**.
  L’hébergement et les références ne constituent pas une approbation de GM-OS par leurs auteurs.
- Le site attribue les rencontres alternatives à **« Faire du Vieux avec du Neuf »**, dans
  **Le Tinkle Bavard n° 8**, via **L’Omnirêve**. La provenance devra être conservée si ces
  variantes sont adaptées ; leur présence dans le script ne valide pas leur inclusion par défaut.
- Les illustrations et bibliothèques tierces de l’archive ne sont pas incluses dans ce paquet
  d’étude suivi par Git. Leur éventuelle reprise nécessitera leurs crédits et conditions propres.

## Consigne pour le futur module TMR

Décision de David, **18/10/2026** : « n’oublie pas effectivement de créditer le travail d’autrui ».

Le futur module doit proposer une entrée **« Crédits et licences »** accessible dans son
interface, reprendre les auteurs et sources effectivement utilisés, conserver leurs notices
dans les fichiers et dans le paquet distribué, et décrire les adaptations effectuées.
Actualiser ce document à chaque reprise ou modification de code tiers. L’attribution de la
réalisation GM-OS à Codex ne remplace jamais les crédits des contributions d’origine.
