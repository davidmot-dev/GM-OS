# RPG Banner Builder

Plugin privé pour les bannières GM-OS : jeu ou campagne, références facultatives, cohérence avec une identité visuelle fournie, invite anglaise et génération avec l’outil d’images de l’hôte. L’outil HTML joint fonctionne hors ligne pour le recadrage, l’aperçu et l’export à 2400 × 600 en JPG/WebP sous 500 Ko.

Le plugin ne fournit ni modèle d’image, ni serveur, ni accès aux données GM-OS. Si la génération est indisponible, il fournit le prompt et signale cette limite. Choisir le fichier dans l’éditeur du pilote → Bannière de l’en-tête.
