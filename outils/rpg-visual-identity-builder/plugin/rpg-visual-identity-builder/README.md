# RPG Visual Identity Builder

Plugin privé, version 0.1.0, construit à partir des instructions de David dans GM-OS.

Joindre une à quatre images, ou décrire un style, puis préciser le jeu ou la campagne. Analyse en français ; résultat anglais STYLE / AVOID (60 / 15 mots maximum). Ajuste une identité de campagne ou corrige une génération ratée.

Copier ces valeurs dans l’éditeur « Identité visuelle » de GM-OS. Aucun accès automatique aux campagnes, aux pilotes ou aux fournisseurs d’images ; aucun serveur à installer.
