# Torg — préparer les cartes séparément

Les paquets appartiennent au jeu. Le pilote original fourni garde leurs trois définitions ; le .gmos ne copie pas leurs mains ou leur pioche. L’import natif est testé en conservant un paquet et une main sentinelles.

1. Dans Deck-OS, vérifier le jeu Torg et les rôles Action, Destin, Cosm. Les chemins du pilote pointent vers les images de l’application dans assets/decks/torg/. Pour une autre machine, régler le dossier des images avec le sélecteur natif si nécessaire.
Le pilote fourni déclare encore cinq cartes du Destin : dans Deck-OS, modifier explicitement leur nombre à **10**, puis vérifier les fichiers card_01.jpg à card_10.jpg. Les cinq nouvelles faces ont été relues ; Relation reste absente. Les mains existantes sont à préserver.

2. Pour les exercices à défausse, choisir le mode **Standard**, et ouvrir le paquet Destin aux joueurs si la pioche doit leur être proposée. Le pilote original n’est pas modifié par ce lot ; ces réglages restent explicites.
3. Décrire une carte d’Action d’après l’image, pas de mémoire. Exemple vérifié : index 12, Gardez la pose !, imprimée 13-N ; standard Héros/Un de plus !, dramatique Vilains/Fatigués ; Intimidation/Provocation approuvées.
4. Le sous-ensemble Destin disponible comporte Monologue, Plan de secours, Romance, Seconde chance, Échappé belle, Second souffle, Reconnexion, Revers, Précision et Étape A. Il ne contient pas Relation. Ajouter les vraies cartes de votre paquet complet pour le cas positif de Populaire ; ne pas redessiner de faux effets officiels. Avec dix cartes, les échanges à deux et les refus sont essayables après préparation manuelle ; pas trois mains complètes.
5. Le paquet Cosm est rattaché à Prime Terre dans le pilote. Annoncer le cosm courant et choisir un paquet réellement compatible ; un paquet absent ne crée pas de carte. Les effets imprimés restent arbitrés.

## Portée des distributions collectives

Fin de scène et Fin d’Acte ciblent actuellement **tous les PJ de la campagne**, pas seulement ceux de la séance : ici neuf, principaux et profils de recette compris. Une distribution vide à quatre demande donc 36 cartes (45 sous Héroïsme). Pour jouer l’histoire avec trois héros, distribuer manuellement aux seuls principaux ; réserver les distributions collectives aux ateliers et à un poste d’essai. Ne pas confondre ce comportement avec une restauration locale.

Les cartes physiques complètes peuvent servir à la fiction. Les cas humains restent NON TESTÉS et signalent les préparations manquantes. Les fonctions pures des tests peuvent utiliser des indices synthétiques pour éprouver la conservation des cartes ; elles n’installent aucun faux paquet dans la campagne.
