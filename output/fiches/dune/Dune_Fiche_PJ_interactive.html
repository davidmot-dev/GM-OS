Dune — fiche de personnage

La page originale du PDF est conservée. Saisissez dans les espaces imprimés ; « Zones » affiche leurs contours. Aucun calcul automatique n’est ajouté. Les deux emblèmes de progression et de Détermination sont des emplacements numériques libres : ils ne sont pas des pistes de cases.

Maison : cliquez dans les armoiries pour choisir une image locale. Maj+clic ou un clic droit permet de la retirer, après confirmation. Le JSON contient aussi l’image.

Zoom : 20 à 400 %, Ctrl+molette, Ctrl++, Ctrl+− ; Ctrl+0 ou « Ajuster » ajuste la page à l’écran. Sur un petit écran, augmentez le zoom pour écrire, puis déplacez la page.

La sauvegarde locale appartient à ce navigateur. Exportez régulièrement un JSON pour conserver une copie ou passer sur un autre appareil. L’import remplace la fiche après confirmation et vérifie son modèle.

L’impression restitue la page entière sans les commandes. La fiche est utilisable hors ligne ; son manifeste permet d’importer le modèle dans le moteur GM-OS. La liaison aux champs du pilote se prépare séparément.
