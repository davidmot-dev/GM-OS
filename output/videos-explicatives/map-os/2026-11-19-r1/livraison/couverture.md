# Couverture

Module natif Map-OS : médias image/vidéo, grille, vue, acteurs liés, projection Hub, brouillard rectangle/pinceau/rond/global, ping du Hub, visibilité/déplacement/suppression de pions, tour, magie, météo, heure, sept calques, modèle de terrain et présence de pions, configurations et persistance.

Limites montrées : forme de Danger non appliquée et zones visibles sur le brouillard. Aura non démontrée : attribution de porteur non validée ; commandes physiques, sorties audio et IA non exécutées. Pas de simulation de règles de combat : ce film porte sur le module cartographique. Les guides sont recoupés avec le code et les essais réels.
