# Le Dernier Jour de Hope — vue d’ensemble

> Source: ALIEN_le_jeu_de_rôle.pdf | Pages livre 369-375

## Type de scénario
Mode Cinéma court. Le scénario correspond à un troisième acte compressé, jouable rapidement, avec forte létalité et objectif commun explicite.

## Contexte
Hadley’s Hope est une colonie sur LV-426. Un prospecteur, Russ Jorden, a été ramené infecté. Après sa mort, un parasite s’est échappé dans la base. D’autres colons ont été infectés. Une équipe Weyland-Yutani dirigée par Miranda Reynolds et Theodora Komiskey est arrivée juste avant la dégradation totale de la situation.

## Postulat de départ
Les PJ sont cinq ouvriers ou résidents locaux. Ils comprennent que :
- la colonie est en train de tomber ;
- la hiérarchie locale est absente ou morte ;
- Reynolds et Komiskey sont probablement les seules personnes disposant de l’autorité et des cartes d’accès nécessaires pour utiliser la navette ;
- leur objectif commun est de quitter LV-426 vivants.

## Conditions initiales
- Les PJ ont travaillé loin de la base pendant environ vingt-quatre heures.
- À leur retour, la situation s’est effondrée.
- Le groupe démarre épuisé dans le sas Ouest.
- L’interphone diffuse un faux ou ancien message d’urgence orientant les colons vers la réserve principale du sous-sol.
- Des Xénomorphes passifs sont déjà cachés dans la base.

## Logique centrale
### Si les PJ veulent fuir
Alors ils doivent au minimum :
1. comprendre que la colonie n’est plus récupérable ;
2. trouver Reynolds ou Komiskey ;
3. récupérer une carte d’accès ;
4. atteindre la navette ;
5. survivre à la dernière complication liée aux œufs / facehuggers.

### Si les PJ s’attardent
Alors le MJ peut activer la pression progressive :
- appels à l’aide ;
- émergence de chestburster ;
- xénomorphes actifs en traque ;
- ruée finale vers la navette.

## Cibles RAG
- extraction de mission ;
- rappel d’objectif ;
- guidage de MJ sur la progression ;
- réponses IA du type « que doivent faire les PJ ensuite ? ».
