# Système : L'Appel de Cthulhu (v7)

## Mécaniques de Base
- **Jet de Caractéristique** : Lancer 1d100 sous la valeur de la caractéristique ou compétence.
- **Niveaux de Succès** :
  - Succès Majeur : <= 1/2 de la valeur.
  - Succès Extrême : <= 1/5 de la valeur.
  - Critique : 01.
- **Santé Mentale (SAN)** : Perte de points en cas de choc horrifique. Si perte de 5+ points en une fois : test d'Intelligence pour éviter la folie passagère.

## Combat
- L'initiative est déterminée par la caractéristique **Dextérité (DEX)**.
- Les armes à feu ont souvent plusieurs tirs par round.
